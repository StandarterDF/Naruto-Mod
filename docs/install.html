Установка и запуск

Мод ставится как обычный Forge-мод для Minecraft 1.20.1. Ниже — что нужно, откуда взять jar, куда его положить и что сделать в первые минуты в игре, чтобы получить первую технику. Рецепты новых предметов — на странице «Предметы».

О зависимостях

В mods.toml мод объявляет обязательную зависимость sekclib с диапазоном [1.0.0,2) (в build.gradle она подключена как обычная библиотека, а не вшита в jar). При этом ни README мода, ни эта документация о ней не упоминают. Если лаунчер всё-таки жалуется на отсутствие sekclib — это расхождение между манифестом и описанием, а не ваша ошибка установки.

Установка

Для обычной игры всё сводится к трём шагам: поставить Forge, положить jar в mods, запустить профиль Forge.

  1. Установите Forge 47.1.62 для Minecraft 1.20.1 и запустите игру хотя бы раз — чтобы появился профиль Forge и папка .minecraft.
  2. Возьмите файл мода (.jar). Готовые сборки публикуются в релизах форка: github.com/StandarterDF/Naruto-Mod/releases. Если в релизе нет прикреплённого jar — соберите его сами (см. «Сборка из исходников» ниже).
  3. Положите jar в папку mods рядом с игрой. Путь по умолчанию на Windows: %appdata%\.minecraft\mods. Папку можно создать вручную.
  4. Запустите игру профилем Forge 1.20.1. Если мод загрузился, в игре появятся его предметы и механика техник.

Сборка из исходников

Нужен JDK 17: враппер проекта (Gradle 8.1.1) не запускается на более новых JVM. Сборка — обычной командой Gradle, готовый файл появится в build/libs/. 

$env:JAVA_HOME='C:\Program Files\Java\jdk-17'
.\gradlew.bat build

Для запуска из исходников в репозитории есть готовые скрипты: они сами находят JDK 17. 

.\run-dev-client.bat      # дев-клиент, мир и логи лежат в .\run
.\run-dev-server.bat      # дев-сервер, нужен run/eula.txt

Первые шаги

Прежде чем кастовать, нужно стать ниндзя — это делается прямо из меню техник, без команд и предметов.

Шаг 1

Посвящение в ниндзя

  1. Нажми J — откроется меню техник.
  2. Нажми «Стать ниндзя» (naruto.gui.jutsu.enable). Обратно — кнопкой «Я передумал» (naruto.gui.jutsu.disable).
  3. Пока ты не ниндзя, список техник в меню не показывается — вместо него подсказка.
  4. После посвящения меню показывает весь список, разбитый по группам и страницам.
Шаг 2

Первый каст чакры

  • Набери C и зажми последнюю клавишу — это канальный «Чакра-заряд».
  • Стоя на земле, пока держишь комбо, чакра набирается по +1 за тик. На бегу и в воздухе — только +0.2.
  • Мгновенные техники, наоборот, не зажимаются: набери комбо и просто подожди полсекунды.
  • Переключатели включаются тем же комбо, которым и выключаются.

印 Шаг 3

Клавиши по умолчанию

  • X — Прыжок (Leap). Работает только с земли и стоит 10 стамины.
  • C / V / B — «1», «2» и «3» в последовательности комбо.
  • J — меню дзюцу и включение режима ниндзя.
  • Прыжок в воздухе — двойной прыжок, сам по себе, без комбо.

Клавиши можно переназначить; в меню они рисуются латинскими буквами по коду клавиши, поэтому на русской раскладке комбо не превращается в кириллицу.

Шаг 4

На что смотреть в интерфейсе

  • Чакра — 100 максимум, +0.05 за тик после задержки регенерации.
  • Стамина — 100 максимум, +0.4 за тик; её едят прыжок, врата и мягкая посадка.
  • Замены — всего 3, восстанавливаются по одной за время, которое задаёт опция substitutionRegenTime; их тратит «Подмена».
  • Сенин-мана — отдельная зелёная полоска над чакрой, появляется, когда есть что показывать.

Как устроены ресурсы →

Три правила, которые объясняют половину «неудачных» кастов

  • Клоны требуют чакра-печать в инвентаре: одна печать за каст, независимо от числа клонов. В креативе печать не нужна.
  • После каждого каста ресурс не восстанавливается какое-то время — это и есть «настоящая» цена техники.
  • Набор техник читается при запуске игры, поэтому изменения подхватываются только полным перезапуском.
