Версия мода 1.8.1 · Minecraft 1.20.1 · Forge 47.1.62.
Числа на страницах — из кода, а не из старых версий.

Начало

Установка

Мод ставится как обычный Forge-мод: Minecraft 1.20.1, Forge 47.1.62, готовый jar — в папку mods. Сборка из исходников нужна только если ты правишь код или хочешь собрать последний снимок.

Что нужно

КомпонентВерсияЗачем
Minecraft1.20.1Мод собран строго под эту версию.
Forge47.1.62 (или совместимый 47.x)Загрузчик мода.
Java17Требование Minecraft 1.20.1 и мода. Для игры Forge обычно ставит её сам.

Java 25 не подойдёт для сборки

Если собираешь сам, Gradle 8.1.1 работает только на JDK 17. Запуск игры через официальный лаунчер для 1.20.1 тоже идёт на Java 17.

Установка на клиент

  1. Поставь профиль Forge 1.20.1 (установщик Forge → клиент). Запусти игру один раз, чтобы появилась папка .minecraft для этого профиля.
  2. Открой %appdata%\.minecraft\mods (Windows) или папку mods своего лончера.
  3. Положи туда NarutoMod-…-universal.jar. Больше ничего не нужно: мод самодостаточен.
  4. Запусти игру. В списке модов должна появиться запись Naruto Mod, а в управлении — категория Naruto Mod с клавишами техник.

Для рецептов удобно поставить JEI (Just Enough Items) — в дев-сборке мода он подключён как удобство для разработки. Это не требование мода: все 71 рецепт есть на странице Предметы и рецепты.

Играешь не первый раз?

Загляни в «С чего начать»: без нажатия J и кнопки Become a ninja техники не кастуются, и это самая частая причина «мод не работает».

Установка на сервер

  1. Серверный Forge 1.20.1 версии 47.1.62 (или другой 47.x), Java 17.
  2. Тот же jar положить в серверную папку mods.
  3. Первый запуск создаст config/naruto-mod.toml — это общий (common) конфиг: его читают и клиент, и сервер.
  4. Настроить конфиг под свой сервер (например, выключить чутьё руды на публичном сервере — это фактически краткий x-ray) и перезапустить сервер.

Клиенту для подключения нужен только сам мод. Конфиг клиента имеет приоритет для клиентских ключей (например, вид полоски чакры), серверные ключи раздаются с сервера при входе.

Сборка из исходников

Репозиторий — StandarterDF/Naruto-Mod (форк), оригинал — sekwah41/Naruto-Mod. Сборка требует JDK 17:

$env:JAVA_HOME='C:\Program Files\Java\jdk-17'
.\gradlew.bat build

Готовые файлы появятся в build/libs/:

ФайлЧто это
NarutoMod-1.20-1.8.1-SNAPSHOT-universal.jarРабочий мод — этот файл ставится в mods.
NarutoMod-1.20-1.8.1-SNAPSHOT-sources.jarИсходники для чтения.
NarutoMod-1.20-1.8.1-SNAPSHOT-deobf.jarПромежуточный артефакт сборки, в игру не ставится.

Дев-клиент и дев-сервер (для тестов в игре, с JEI в клиенте) запускаются скриптами run-dev-client.bat и run-dev-server.bat — они сами находят JDK 17 и запускают Gradle с --offline, поэтому интернет для дев-сборки не нужен: все зависимости, ассеты и нативы уже в локальном кэше. После изменения зависимостей один раз запустите с set NARUTO_ONLINE=1, чтобы Gradle смог их скачать.

Файл настроек

Конфиг создаётся при первом запуске по пути config/naruto-mod.toml. Все ключи сгруппированы по разделам: server.player.energy_bars, server.player.mastery, server.weapons, server.kamui, client.ui и другие. Полный список с комментариями — на странице Настройки сервера.

Старый конфиг перекрывает новые значения

Если ты обновился с прошлой версии, уже существующий naruto-mod.toml остаётся как есть: например, в новых версиях базовая чакра снижена до 25, но в старом файле останется прежнее число. Чтобы увидеть новые значения по умолчанию — удали файл или поправь ключ вручную.

Если что-то не работает

  • Игра падает при запуске. Проверь версии: 1.20.1 + Forge 47.x + Java 17. Другой Forge (не 47.x) или 1.20.4 — самая частая причина.
  • Мод не появился в списке. Убедись, что положил именно universal.jar, а не deobf или sources.
  • Каст не срабатывает. Сначала J → Become a ninja, потом нужный узел в дереве скилов. Проверь задержки комбо и зажми последнюю клавишу для каналов.
  • Сервер упал при первом снаряде. Это признак того, что в сборке не оказалось JSON типа урона мода — сообщи об этом в issues, это баг сборки, а не настройка.
