# research/ — исследовательские материалы

Не входит в публикуемый сайт (`docs/`) и в сборку мода. Здесь хранятся справочники по вселенной, собранные как основа для портирования механик.

## NARUTO_TECHNIQUES.md

Полный свод техник «Наруто» (мангa, аниме, филлеры, «Боруто»): ниндзюцу всех стихий, тайдзюцу/нинтайдо, кэндзюцу/букидзюцу, гэндзюцу, фуиндзюцу, додзюцу, клановые хидэн, бидзю/дзинтюрики, сендзюцу/рикудо и сводка «что уже есть в моде».

* Легенда канона: `[M]` манга · `[A]` аниме · `[F]` филлер/фильм · `[N]` ранобэ · `[G]` игра · `[B]` «Боруто» · `?` спорно.
* Раздел **§9** — маппинг канона на текущие способности/предметы мода и приоритетный список кандидатов на портирование.

## MOD_BACKLOG.md

Бэклог «что ещё можно добавить в мод»: системные пробелы (нет прогрессии/кланов/декларативного контракта способности), техдолг (найденные баги и мёртвый код), контентные кандидаты по темам (стихии, додзюцу, тайдзюцу, кэндзюцу, гэндзюцу, фуиндзюцу, сущности, предметы, клиент), быстрые победы и предлагаемый порядок работ. Каждый кандидат привязан к канону (§ исследования) и к конкретным точкам расширения в коде.

## Структура

Файл `NARUTO_TECHNIQUES.md` **собирается** из `parts/*.md` (по файлу на раздел). Правьте части, а не собранный файл.

```powershell
# пересборка после правки parts/
$dir = 'research'
$parts = @('00-overview.md','01-basic-elements.md','02-advanced-releases.md','03-ninjutsu-general.md','04-taijutsu.md','05-kenjutsu-weapons.md','06-genjutsu-fuinjutsu.md','07-dojutsu-kekkei.md','08-biju-rikudo-boruto.md','09-mod-mapping.md')
$chunks = foreach ($p in $parts) { (Get-Content -Raw -Encoding UTF8 "$dir\parts\$p").TrimEnd() }
[System.IO.File]::WriteAllText((Resolve-Path "$dir\NARUTO_TECHNIQUES.md"), (($chunks -join "`r`n`r`n") + "`r`n"), (New-Object System.Text.UTF8Encoding $false))
```
