## Часть I. Системные вещи (дают больше всего контента сразу)

### I.1 Прогрессия и изучение техник — **сейчас её нет**

**Проблема.** Статус «ниндзя» — это один `boolean` (`INinjaData#isNinjaModeEnabled`), включаемый кнопкой в меню `J`. Все техники из `COMBO_MAP` доступны сразу, как только статус включён. Нет рангов, опыта, миссий, деревни, очков навыков и дерева прокачки.

**Что даёт.** Это главный недостающий «скелет» мода: сейчас все техники — просто список, а не прогрессия. Прогрессия превращает каждую новую технику в награду и растягивает контент, которого уже много.

**Как встроить (по образцу `seninMana`/`ninjaModeEnabled`):**

| Шаг | Точка в коде |
| --- | --- |
| Поля ранга/опыта/очков | `INinjaData` + `NinjaData`: `@Sync(minTicks=1)` + NBT в `serializeNBT`/`deserializeNBT` |
| Гейт каста | `network/c2s/ServerAbilityActivatePacket` и `ServerAbilityChannelPacket` — рядом с существующей проверкой `isNinjaModeEnabled` |
| Данные «кто что открыл» | `Set<ResourceLocation> unlockedAbilities` в данных игрока (`@Sync`) |
| Экран дерева | новый `Screen` по образцу `JutsuScreen` (там уже есть категории `CATEGORIES`) |
| Команда | `commands/NarutoCommands` → новая `literal("ninja")` (сейчас есть только `/jutsu list`) |
| Конфиг | `NarutoConfig` — старт рангом, множители опыта; заодно раскомментировать `startsAsNinja` |
| Достижения | `data/narutomod/advancement/` (папки ещё нет) — «стать генином», «открыть Расенган» |

**Усилие: L.** Риск средний (затрагивает все техники, но через одно место — пакеты активации).

### I.2 Клановая система — реестр есть, системы нет

`clans/Clans.java` и реестр `NarutoRegistries` существуют, но класс **пуст**. Кланы — половина узнаваемости вселенной.

**Предложение:** при первом включении статуса — выбор клана (Учиха, Хьюга, Нара, Яманака, Акимичи, Абурамэ, Инудзука, Узумаки, Сенджу, Ходзуки…, см. §7.2). Клан даёт: стартовые техники, пассивку (через `LivingTickEvent`, как бонусы брони в `NarutoArmorEvents`) и визуальный маркер.

**Усилие: M–L.** Риск низкий (аддитивно), но требует экрана выбора и балансировки.

### I.3 Декларативный контракт способности

Сейчас нет единого «можно ли кастовать»: каждое `handleCost` само пишет `jutsu.fail.*`, требования (печать, инструмент, кирка) проверяются вручную. Стоимость и КД — не часть базового контракта.

**Предложение:** в `Ability` добавить `chakraCost()`, `staminaCost()`, `requiredRank()`, `canUse(player, data)`; централизованно вызывать их в пакетах. Это естественно включает I.1 и убирает дублирование.

**Усилие: M.** Риск средний (рефакторинг всех способностей), но лучше сделать до их массового добавления.

### I.4 Датаген не запускается — нет рецептов, лута, ачивок

Классы `datagen/NarutoRecipeGen`, `NarutoSpriteSourceGen`, `NarutoDataGenerator` есть, но `src/generated/resources` пуст, поэтому в jar попадают только **5 рукописных рецептов** (`chakra_battery`, `chakra_seal`, `military_pills`, `ramen`, `worker_seal`). Рецепты брони/кунаев/катаны из генератора теряются. Нет `advancement/`, `loot_table/`, `tags/item`.

**Предложение:** либо один раз прогнать `runData` и закоммитить `src/generated/resources`, либо продолжать руками. Ачивки (advancement) особенно нужны для прогрессии (I.1).

**Усилие: S–M.** Риск низкий.

## Часть VIII. Риски и правила, которые надо помнить

* **Новый тип урона** = константа в `NarutoDamageTypes` **и** рукописный JSON в `data/narutomod/damage_type/`, иначе сервер падает при первом попадании.
* **Один `AttributeSupplier` на `EntityType`** — вариативные статы ставить после создания; персистентность переприменять в `readAdditionalSaveData`.
* **Клиентский код — только через `DistExecutor`/`Dist.CLIENT`**, иначе выделенный сервер упадёт при загрузке класса.
* **Комбо — `HashMap` без приоритетов**: одна техника на комбо, конфликты только логируются. Помнить, что `C`/`V`/`B` заняты базовыми способностями (одиночные нажатия) — новые комбо не должны быть их префиксами-двусмысленностями.
* **Порядок пакетов в `PacketHandler.init()` = ID**; менять порядок нельзя без разрыва совместимости.
* **Кулдаун работает только у INSTANT** (через `ServerAbilityActivatePacket`) — для TOGGLE/CHANNELED нужен свой механизм.
* **Датаген не запускается**: любой новый рецепт/лут/ачивка — руками (или сначала настроить `runData`).
* **Измерения**: проверять `Server#getLevel(...) != null` перед телепортом.
